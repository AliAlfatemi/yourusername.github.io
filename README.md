# Portfolio Website

A single-page portfolio built with HTML, Tailwind CSS, and JavaScript.
The page includes an introduction, skills, project cards, and contact sections.

## Local preview

```bash
git clone https://github.com/AliAlfatemi/yourusername.github.io.git
cd yourusername.github.io
python3 -m http.server 8000
```

Open [localhost:8000](http://localhost:8000/) in a browser. Tailwind CSS and
Lucide icons are loaded from external CDNs.

## Editing

[index.html](index.html) contains the page markup, custom styles, and
client-side interactions. Update the profile, project links, and contact
information in that file.
